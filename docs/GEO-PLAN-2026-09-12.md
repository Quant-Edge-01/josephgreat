# Joseph The Great — GEO implementation plan

Date: 12 September 2026. Authorized by founder. Baseline: dd7daf6.

## Goal and boundary
Improve discoverability for Toronto small businesses seeking reels, Meta ads and websites within CAD 700–1,000/month. No promise of ChatGPT recommendation, first position, indexation or sales. Preserve the existing homepage, artwork, type, colours, entry animation and music.

## Inspection before edits
- Clean main matching origin/main; existing Next.js/Vercel site.
- Public apex domain returns 308 to https://www.josephthegreat.art/.
- /robots.txt and /sitemap.xml both return 404.
- No service pages; homepage and case-study canonicals absent; default metadataBase uses apex rather than final www hostname.
- Four portfolio cases, saved evidence images, existing price/CTA and analytics code inspected. Campaign accounts are not independently revalidated.
- Focused web searches did not return relevant indexed site results or substantive independent reporting. This is a search sample, not proof of zero indexation or no coverage anywhere.

## Ordered work
1. Make www the consistent canonical origin; unique page metadata and relevant share previews.
2. Add robots.txt permitting OAI-SearchBot and standard crawling, plus sitemap.xml. Do not equate GPTBot training permission with search eligibility.
3. Add visible, useful server-rendered service hub, pricing explanation, founder page and five distinct industry pages. Link each to relevant existing evidence; clearly identify illustrative ideas and sectors without published case results.
4. Add factual Organization/Person/Service/WebPage/Breadcrumb JSON-LD, matching visible information. No invented address, reviews, awards, clients, revenue or guarantees.
5. Add quiet footer discovery links and related-service links on cases. Leave existing homepage sections and styling intact. New informational pages open directly for everyone; keep the original jar entrance on existing routes.
6. Build, validate HTTP responses, canonicals, sitemap, structured data, server HTML and links. Browser-check desktop/mobile and original jar/music.
7. Publish to existing Vercel flow and verify public output. Produce a separate handoff report with evidence, limitations, measurement and remaining account-level tasks.

## Deliberately excluded
- Mass-produced city/keyword pages, fake customer stories, hidden AI instructions, invented citations.
- llms.txt as a purported ranking mechanism: no established requirement in the consulted search guidance.
- Wikipedia publication without substantial independent coverage; a neutral own-site biography is appropriate now.
- New tracking vendors, CRM, paid ads or outbound pitches.
